## v0.1 (2026-11-22): 프롤로그 + 1~3장
- 예시 공시는 모두 "가상의 A사"로 명시(실제 사례 아님)
- 장면은 독자 시점. 작가 경험으로 지어낸 문장 없음

### 실제 사례로 바꿀 자리
| 위치 | 지금 | 바꿀 것 |
|---|---|---|
| 프롤로그 | 점심시간 증권 앱 알림(가상의 A사 공급계약) | 작가님이 뉴스보다 공시를 먼저 봤거나, 제목과 원문이 다르게 읽혔던 실제 공시(회사명 가림, 접수일) |
| 1장 | 가상 공급계약(120억 원, 매출 400억 원, 2년) | 실제 공급계약 공시 + 같은 날 기사 제목 |
| 3장 | 가상 유상증자(기존 1,000만 주, 신주 250만 주) | 실제 유상증자 공시 |

### 집필 시점 확인 필요(사실 점검)
- DART 공시 유형 메뉴 이름과 분류(정기공시·주요사항보고·발행공시·지분공시·기타공시·외부감사관련·거래소공시 등) — 2장 표의 갈래 이름이 현재 화면과 같은지
- KIND(상장공시시스템)에서만 보이는 공시 범위
- 정정 공시 제목 표기([기재정정] 등)와 정정 전후 비교표 형식

### 숫자 검산
| 계산 | 결과 |
|---|---|
| 120억 ÷ 400억 | 30% |
| (120억 ÷ 2년) ÷ 400억 | 15% |
| 250만 ÷ 1,000만 | 25%(기존 대비) |
| 250만 ÷ 1,250만 | 20%(증자 후 대비) |
