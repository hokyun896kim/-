# 치트시트: 판단 규칙

> 원고의 판단 규칙만 모았습니다. 학습용이며 매수·매도 판단에 쓰지 않습니다.

## 뉴스를 받으면 (결정 흐름)
- 단어가 막히면 → 단어는 그때 찾고 **빠진 칸(B)**부터 본다 (1장)
- 매크로 뉴스면 → 6단계(사건·금리·환율·섹터·실적의 줄·내 계좌) (1장)
  - 좋다/나쁘다가 궁금하면 → "누구에게, 나는 어느 쪽" (3·4·6장)
  - 중앙은행 뉴스면 → 결과 말고 **말투**를 본다. 식히나, 풀어주나 (7장)
  - 전쟁·지정학 뉴스면 → 공포 말고 **경로**로 읽는다 (8장)
- 기업 뉴스면 → 체격(매출)·근육(영업이익)·속도(온도차)·숨(현금흐름)·계절·기대 (9~14장)
- 믿어도 되나 싶으면 → 출처 → 인과 → 부재 → 편향 → AI 답 재검증 (19장)

## 규칙: X면 Y, 왜냐하면 Z
| X | Y | Z (원고 근거) |
|---|---|---|
| 물가가 예상보다 높다 | 금리 인하가 늦어질 가능성부터 본다 | 물가 뉴스는 금리 뉴스의 예고편 (5장) |
| 고용이 강한데 시장이 하락했다 | 임금→물가→금리 사슬을 본다 | 좋은 뉴스가 나쁜 뉴스로 읽히는 장면 (6장) |
| 금리를 동결했다 | 발표문의 톤과 근거를 찾는다 | 숫자는 결과, 말투는 방향 (7장) |
| 유가와 환율이 함께 오른다 | 수입물가 부담이 커졌다고 본다 | 원유는 주로 달러로 거래된다 (8장) |
| 매출은 늘었는데 영업이익이 줄었다 | 재료비·인건비·광고비·가격 인하·할인·효율을 의심한다 | 체격만 크고 근육은 그대로 (9장) |
| 실적 온도차가 + 또는 −다 | 가격·원가·고정비·일회성 중 무엇이 원인인지 묻는다 | 결론이 아니라 질문의 출발점 (10장) |
| 흑자인데 자금난이다 | 현금흐름과 부채를 본다 | 회사는 이익이 아니라 현금으로 버틴다 (11장) |
| 적자인데 채용을 늘린다 | 산업의 봄인지 확인한다 | 시장을 만드는 중일 수 있다 (12장) |
| 흑자인데 산업이 겨울이다 | 마지막 수확일 가능성을 열어 둔다 | 계절이 결과를 가른다 (12장) |
| 실적이 좋은데 반응이 약하다 | 이미 예상된 실적이었는지 본다 | 시장은 기대를 산다 (14장) |
| PER이 낮다 | "싸다"고 단정하지 않는다 | 기대가 낮은 이유가 있을 수 있다 (14장) |
| 제목이 단정적이다 | 원문의 핵심 문장과 조건을 대조한다 | 요약하는 과정에서 온도가 바뀐다 (15장) |
| "A 때문에 B"라고 한다 | 시간 순서·다른 원인·중간 과정을 확인한다 | 경제는 실험실이 아니다 (16장) |
| 공식 자료에 없다 | "현재 확인되지 않음"으로 두고 판단을 유보한다 | 확인 안 됨 ≠ 사실 아님 (17장) |
| 이미 결론이 서 있다 | AI에게 가장 강한 반대 근거를 묻는다 | AI는 질문을 따라온다 (18장) |
| AI가 답했다 | 사실과 추정을 나누고 출처를 표시해 달라고 한다 | AI로 검증하되 AI를 검증한다 (19장) |

## 기준값·기본값
- 6단계 프레임: 입문자는 1~5단계, 주식·ETF 경험자는 6단계까지 (1장)
- 하루 10분 배분: 시장 분위기 1분, 금리 2분, 환율 2분, 핵심 뉴스 1개 3분, 내 돈 연결 2분 (2장)
- 하루 루틴: 아침 10분·저녁 10분, 부담되면 5분. 저녁에는 뉴스 **하나만** (20장)
- 주말 루틴: 10~15분, 세 줄로 정리 (21장)
- 원고의 예시 숫자: 금리 0.25%p(3장) / 환율 1,300→1,400원, 100달러 13만→14만 원(4장) / 점심 3,000→4,000원, 30,000원으로 10끼→7끼 정도(5장) / 커피 4,000원 × 100잔 = 40만 원(9장) / 매출 +20%에서 영업이익 +5% vs +40%(10장)

## 이런 신호가 보이면
- 단어는 다 아는데 설명이 세 번째 칸에서 꼬인다 → 연결고리를 놓쳤다 (프롤로그)
- 볼수록 더 헷갈린다 → 해석만 쌓이고 있다. 원문으로 돌아간다 (15장)
- 반례를 "그 집이 특별한 거겠지"로 넘긴다 → 확증편향 (18장)
- "위기·급등·충격·경고·불안"이 그날만 시끄럽다 → 노이즈일 수 있다 (21장)
- "다 조작이야"라는 말이 나온다 → 회의가 아니라 냉소다 (15장)
- AI에게 "내 생각이 맞다는 근거를 찾아줘"라고 하고 있다 → 결론을 유도하고 있다 (18장)
