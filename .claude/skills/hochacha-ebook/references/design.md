## 책마다 방향 5줄 (모든 시각물의 기준)
제품 / 성격 2~3단어 / 세계 / 결정적 장면 1~2개 / 시그니처 1개. "깔끔한·세련된·모던·프리미엄"은 금지어(어느 책에나 맞는 말).
| 책 | 세계 | 시그니처 |
|---|---|---|
| 2권 경제뉴스 | 신문 지면·형광펜·빨간 펜 교정 | 물음표 길 |
| 3권 매매법 검증 | 모눈 차트지·실험 노트 | 체에 걸러지는 ▶ |
| 4권 호재일까, 함정일까 | 공시 원문 표·형광펜·접수 시각 | 원문 표 한 줄(계약기간)에만 형광펜 |
| 5권 매수 의견만 있는 나라 | 트레이딩 터미널 화면·리포트 첫 장·고정폭 숫자, 검푸른색+신호 빨강 | 전부 BUY인 상태판에서 한 칸만 열려 "× PER 20.0x"에 밑줄 |

5권부터 본문 그림은 CHART(데이터)·ARTIFACT(화면/문서 자체)·DRAWING(손그림 선 개념도) 세 갈래로 장마다 3개 안팎(`ebook/infographic5.py`). 손그림 선은 개념도에만, 데이터 그림은 정밀한 선. 고정폭 글꼴(JetBrains Mono)엔 한글이 없으니 한글이 섞인 문자열은 고딕으로 자동 전환.

## 표지
- 두 색 + 콘셉트 그림 하나 + 편집 타이포그래피. 그라데이션·글로우·광택·배지 남발 금지
- **판정: 제목만 바꿔 다른 책에 써도 어울리면 실패**
- 시리즈 표지끼리 같은 템플릿 금지(2·3권은 바탕색·정렬·그림 언어를 모두 다르게 했다)
- 필수 글자: 제목·저자명·출판사명(유페이퍼)·시리즈 표기. 부제는 제목보다 작게
- 이미지 생성 도구를 쓸 때: 주제 한 문장 → 배경 → 빛과 팔레트(HEX) → 스타일 1개 → 구도(제목 자리 비움) → 제외(글자·로고·워터마크) → 2배 해상도. 글자는 이미지에 굽지 말고 SVG로 얹는다. 오브·네뷸라·홀로그램·로봇·뇌·로켓·크리스털·필름 그레인 요청 금지

## 인포그래픽 (본문 그림)
1. 표나 문단보다 더 가르칠 때만 그린다
2. 강조색은 그림당 1~2곳. 나머지는 남색·회색 단계
3. 대비: 글자 4.5:1 이상, 선·점 3:1 (생성기에서 assert)
4. 글자 크기는 역할 4단계(title·head·body·note)만. 2400px 캔버스(본문 118mm)에서 하한 40px
5. 좌표는 8의 배수, 바깥 여백 80, 간격 48/64/96
6. 개수 예산: 막대·폭포 8, 선 5계열, 단계 7. 넘으면 그림을 나눈다
7. 정직한 척도: 막대 축 0부터, 시간 간격 비례
8. 증감은 색이 아니라 **채움/비움**으로(흑백 인쇄 대비)
9. **데이터 계약**: 그림의 숫자는 계산으로 만들고 원고 문자열과 대조(infographic4.py `must_be_in_md`)
10. 주석 2개까지, 사선 연결선·큰 둥근 알약·그림자 금지
11. 생성 직후 PNG를 눈으로 확인(겹침·잘림·빈 공간)

알려진 개선 과제(2권 infographic2.py): 보조 글자 #8A8478(3.53:1)→#6B6558, 주황 글자 #D9542B(3.8:1)→#B4421F. 2권 재제출·종이책 때 반영.

## 홍보물 (상세페이지·카드뉴스·랜딩)
- 규격: 인스타 1080×1350 / 스토리 1080×1920, 핵심 요소는 중앙 70~80%. 인쇄물 300dpi·CMYK·도련 3~5mm
- 한 장에 서체 2개 이하, CTA 1개, 밝은 요소 1개, 글자 면적 20% 미만(광고)
- 카피: 느낌표 없음, 과장어 없음, 검증 불가 수치 금지, 다른 책에 붙여도 통하는 문장 금지. humanize-korean으로 윤문
- 같은 크기 카드 나열 = 템플릿. 장마다 비주얼 넣지 말 것
- HTML로 만들고 Chromium(Node Playwright, /opt/pw-browsers)으로 2배 캡처
