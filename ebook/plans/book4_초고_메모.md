# 『사인은 내일 할게요』 초고 v0.1 메모

원고: `ebook/source/book4.md` (프롤로그 + 1~3장)

## 실제 사례로 바꿀 자리

| 위치 | 지금 장면(독자 시점, 일반 장면) | 바꿀 수 있는 실제 사례 |
|---|---|---|
| 프롤로그 | 상담 창구에서 서명란 위에 멈춘 펜 | 작가님이 실제로 사인을 미뤘거나, 미루지 못해 후회한 돈 결정 |
| 1장 | 마트 정수기 렌털 "하루 천 원" | 실제 렌털·약정·구독 경험 |
| 2장 | 대출 상담 "고정 4.5% / 변동 4.0%" | 실제 대출 때 금리 유형을 고른 경험 |
| 3장 | 갈아타기 앱 알림 "예상 금리 4.2%" | 실제 갈아타기를 고민하거나 실행한 경험 |

실제 사례를 쓸 때는 1인칭("저는 그날…")으로 바꾸고, 금액은 그대로 쓰거나 비율을 유지한 채 반올림합니다.

## 숫자 검산 (모두 예시값, 원리금균등)

| 계산 | 결과 |
|---|---|
| 정수기 29,900원 × 36 | 1,076,400원 |
| 12개월 뒤 해지 위약금(남은 24개월의 30% 가정) | 215,280원 |
| 월 29,900원 36개월 연 3% 월복리 적립(세전) | 약 1,124,855원(이자 약 48,455원) |
| 2억·30년 4.0% / 4.5% / 5.0% / 3.0% 월 상환액 | 954,831 / 1,013,371 / 1,073,643 / 843,208원 |
| 같은 조건 30년 총이자 | 1억 4,374만 / 1억 6,481만 / 1억 8,651만 / 1억 355만 원 |
| 1.5억·20년 5.0% → 4.2% 월 상환액 | 989,934 → 924,856원(차이 65,078원) |
| 갈아타기 비용 180만 + 15만 = 195만 원, 손익분기 | 약 30.0개월 |
| 5.0% → 4.6% | 957,090원, 차이 32,844원, 손익분기 약 59.4개월 |

## 확인이 필요한 일반 사실

- 위약금 비율, 중도상환수수료율·면제 시점, 부대비용(인지세·설정비)은 상품마다 다름 → 본문에 "가정·예시"로 표기함
- 세제 관련 수치(5장 연금저축·IRP)는 집필 시점에 공식 자료로 확인 후 기입
