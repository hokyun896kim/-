# ① 『나는 AI에게 종목을 묻지 않았다』 — 홍보 전략

| 항목 | 내용 |
|---|---|
| 이 책의 자리 | 시리즈의 출발점. 다섯 권 모두 이 책의 질문에서 나왔다 |
| 누구에게 | AI에게 "뭐 살까요?"를 물어본 적 있는 개인투자자, AI 투자를 막 시작한 사람 |
| 한 줄 메시지 | AI에게 종목을 묻는 순간, 정답이 아니라 허락을 찾고 있었다 |
| 대표 장면·숫자 | "이 종목 살까요?" → "이 종목을 매수 후보로 검토하려면 어떤 조건을 확인해야 하나요?" (허락은 그날만 편하고 기준은 다음 매매에도 남는다) |
| 다른 권과의 연결 | 15장 "리포트를 읽는 질문이 바뀌었다" → ⑤권으로 이어짐 |
