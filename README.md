# 📈 미국주식 분석·매매 시스템

개인투자자가 **미국주식을 체계적으로 분석하고 연습 매매**할 수 있도록 만든
올인원 시스템입니다. 기술적 분석 + 기본적 분석을 종합 점수로 환산해 매수/매도
의견을 제시하고, 웹 대시보드와 모의매매(페이퍼 트레이딩) 기능을 제공합니다.

> ⚠️ **면책**: 본 시스템은 교육·연구 목적입니다. 제공되는 점수와 추천은 투자
> 자문이 아니며, 모든 투자 판단과 결과의 책임은 사용자 본인에게 있습니다.

---

## ✨ 주요 기능

| 영역 | 내용 |
|------|------|
| **선취매 레이더** | 조용한 매집(OBV↑·횡보)+상승여력+변곡 시작 종목을 발굴, 과열·급등은 감점 (남보다 먼저, 느긋하게) |
| **시장 분석** | 나스닥·S&P500·다우 + VIX 공포지수, 50/200일선·골든/데드크로스, **수급(OBV)**·변동성·주요 레벨, **향후 방향성 자동 해설**, 해외 아티클 |
| **헤게모니 스프레드** | 영업이익YoY−매출YoY로 이익 레버리지 발굴, 연간 vs 분기TTM 가속/피크아웃, 랭킹 (yfinance 손익계산서 라이브 계산) |
| **시가총액 스크리너** | 미국 대형주 유니버스에서 **시총 상위 N%** · 섹터로 필터링해 종합점수 랭킹 (실시간 시총 갱신·일일 캐시) |
| **차트 판독(AI 비전)** | 증권사 앱·트레이딩뷰 등에서 캡처한 **차트 이미지를 업로드**하면 Claude 비전 모델이 추세·지지/저항·패턴·보조지표·상하방 시나리오·손절기준을 판독 (Anthropic API 키 필요) |
| **기술적 분석** | 이동평균(SMA/EMA), RSI, MACD, 볼린저밴드 → 매수/중립/매도 신호 |
| **기본적 분석** | PER, PBR, ROE, 순이익률, 매출·이익 성장률, 부채비율, 배당 채점 |
| **종합 점수** | 기술 50% + 펀더멘털 50%(조정 가능)를 합산해 0~100점 + 추천 등급 |
| **최근 실적** | 분기 EPS 예상 vs 실제, **서프라이즈(%)**, 매출 |
| **이벤트** | 다음 **실적 발표일(D-day)**, 배당락일·배당금 |
| **해외 뉴스 분위기** | 헤드라인 수집 + 감성분석 → 긍정/중립/부정 종합 분위기 점수 |
| **웹 대시보드** | 다크 트레이딩 터미널 테마 · 시장 · 선취매 · 스크리너 · 종목 상세 · **차트 판독** · 비교 · 백테스트 · 시뮬레이터 · 모의매매 · 닥터 · 가이드 12개 탭 |
| **모의매매** | 가상 자본으로 매수/매도 연습, 수익률·실현손익 추적(자동 저장) |
| **공포·탐욕 지수** | VIX·모멘텀·RSI·신고가 근접도를 합친 0~100 시장심리 게이지 (CNN 스타일) |
| **종목 비교 레이더** | 가치·성장·수익성·모멘텀·안정성 5팩터를 레이더로 다종목 비교 |
| **시뮬레이터** | 과거 투자 수익 계산(타임머신) + 몬테카를로 미래 주가 확률 분포·목표 도달확률 |
| **포트폴리오 닥터** | 보유종목 분산·집중도·변동성·베타 진단 + 섹터 도넛 + 리밸런싱 제안 |
| **백테스팅** | 매매 전략(골든크로스·RSI·MACD·종합점수)을 과거에 적용해 수익률·MDD·샤프·승률을 단순보유와 비교 |
| **CLI** | 터미널에서 빠르게 종목 분석 |
| **오프라인 모드** | 네트워크 없이도 샘플 데이터로 전체 기능 시연/테스트 |

## 🚀 빠른 시작

```bash
# 1) 의존성 설치
pip install -r requirements.txt

# 2) 웹 대시보드 실행 (권장)
streamlit run stocksystem/app/dashboard.py
# 브라우저에서 http://localhost:8501 접속

# 3) 또는 터미널 CLI
python cli.py analyze AAPL MSFT NVDA   # 특정 종목
python cli.py watchlist                # config.yaml 관심종목 전체
```

### 오프라인/데모로 먼저 둘러보기
실시간 데이터(Yahoo Finance) 접속이 어려운 환경에서는 샘플 데이터로 동작을
확인할 수 있습니다.

```bash
python cli.py analyze AAPL MSFT --provider sample
```
대시보드에서는 사이드바의 **데이터 소스**를 `sample` 로 바꾸면 됩니다.

### 🔬 차트 판독(AI 비전) 사용하기
`🔬 차트 판독` 탭은 Claude 비전 모델을 사용하므로 **Anthropic API 키**가
필요합니다. (다른 기능은 키 없이도 모두 동작합니다.)

```bash
# 1) 키 발급: https://console.anthropic.com  → API Keys
# 2) 환경변수로 설정하면 입력창 없이 바로 사용
export ANTHROPIC_API_KEY="sk-ant-..."
streamlit run stocksystem/app/dashboard.py
```

Streamlit Community Cloud 에 배포할 때는 앱 설정의 **Secrets** 에
`ANTHROPIC_API_KEY = "sk-ant-..."` 한 줄을 추가하면 됩니다. 키를 설정하지
않은 경우 탭 안의 입력창에 직접 붙여넣어 사용할 수도 있습니다(저장되지 않음).
증권사 앱·트레이딩뷰 등에서 캡처한 차트 이미지(PNG/JPG/WEBP)를 올리면
추세·지지/저항·패턴·보조지표·상하방 시나리오·손절 기준을 한국어로 판독합니다.

## ⚙️ 설정 (`config.yaml`)

```yaml
watchlist: [AAPL, MSFT, NVDA, ...]   # 관심종목
data_provider: yahoo                 # yahoo(실시간) | sample(오프라인)
technical:                           # 지표 파라미터
  sma_short: 20
  rsi_period: 14
  ...
weights:                             # 종합점수 가중치 (합 1.0)
  technical: 0.5
  fundamental: 0.5
recommendation:                      # 추천 구간 (0~100)
  strong_buy: 75
  buy: 60
  ...
paper_trading:
  initial_cash: 100000               # 모의계좌 초기자본 (USD)
```

## 🧠 점수 산정 방식 (중급자 참고)

**기술 점수**: 5개 신호(SMA 교차, 가격 위치, RSI, MACD, 볼린저밴드)를 각각
매수(1)/중립(0.5)/매도(0)로 평가해 평균 → 0~100.

**펀더멘털 점수**: 각 재무 지표를 구간별로 채점한 뒤 가중평균.
- 밸류에이션(PER/PBR): **낮을수록** 가점
- 수익성(ROE/순이익률), 성장성(매출/이익): **높을수록** 가점
- 재무건전성(부채비율): **낮을수록** 가점
- 데이터가 없는 지표는 자동 제외 후 가중치 재정규화

**추천 등급**: 종합점수 → 적극매수(≥75) / 매수(≥60) / 보유(≥40) /
매도(≥25) / 적극매도.
