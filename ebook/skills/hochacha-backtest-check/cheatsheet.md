# 치트시트: 의심의 판단 규칙

## 판단 규칙
- **매매법을 받으면** 부록 A 1~5번을 먼저 묻는다. "예" 3개 미만 → 계좌에 넣지 않는다.
- **승률을 들으면** 신호 기준인지 체결 기준인지 묻는다. 신호 기준은 항상 더 좋게 나온다 (14장).
- **수익률을 보면** 같은 날 무작위 매수와 비교한다. 못 이기면 "아무 일도 하지 않은 것" (2장).
- **결과가 좋으면** 깨뜨릴 질문부터: 연도별 분할, 표 전체, 파라미터 흔들기, 시도 횟수 (13·14장).
- **21년 전체가 좋으면** 기간 셋으로 쪼갠다. 최근 몇 년이 폭등장이면 더 의심한다 (+4.0% → 앞 두 시기 손실).
- **"평균보다 낫다"면** 계좌 실험으로 연평균·최대 손실을 따로 본다 (5장).
- **손절선 −5%에 닿으면** 가격 대신 비중·기한·보유 논리를 본다 (6장).
- **사기 전에** 목표·기한·비중을 정한다 (9장).
- **"요즘 잘 되는 방법"이면** 작년의 운인지 묻는다 (13장).

## 신호 판정 결정 트리
- 남들이 신나서 사는 신호인가(급등·거래량 폭발·돌파·정배열 추격)?
  - 예 → 평균적으로 같은 날 비슷한 종목보다 뒤처졌다(1·3·4·5장). "그걸 빼고 남는 이유"가 없으면 패스.
  - 아니오 → 쉬는 순간(눌림)인가, 모두가 던진 순간(급락)인가?
    - 쉬는 순간 → 10장 조건 확인. 기대 수익 작음.
    - 던진 순간 → 11장 네 조건 + 공시 위험 확인(미검증 질문). 30칸 분산 전제.
    - 지수 전체가 한꺼번에 무너짐 → 12장 RSI(21) ≤ 30 확인.
- 외국인이 파는데 주가만 오르나? → 피한다(이탈형) (7장).

## 임계값·기본값
- 목표 익절 고원: 개별 종목 12~25%(9·10장), 급락 반등 15~25%(20% 최적), 지수 +5%.
- 보유 기한: 기준선 60거래일, 급락 반등 10일(20일 이상 악화), 지수 20일.
- 비중: 종목당 3% 남짓(30칸), 눌림목 10%(8칸).
- RSI 고원: 눌림목 65~75, 급락 반등 21일 25~30·14일 20~25, RSI 7일은 실패.
- 비용: ETF 왕복 0.13%면 지수 하루 매매 전멸. 급락 반등은 슬리피지 0.5%에 +8.0%.

## 징후(이러면 의심)
- 이상하게 좋은 숫자 → 미래 엿보기·날짜 정렬·결측 0 처리부터 (2·14장).
- 평균 ≫ 가운데값 → 복권형 분포 (4장).
- 신호가 너무 흔함(13만 개) → 고르는 조건이 아니다 (5장).
- 조건 열 개가 같은 말("지금 강한 종목") → 같은 그물을 열 번 던진 것 (8장).
- 결론 문장만 있고 표가 없음 → 표 전체를 요구 (14장).
- "조금만 바꿔도 무너진다" → 어느 방향으로 얼마나인지 묻는다 (14장).
- 심장이 빨라짐 → "마지막 손님" 경보 (3장).
