# 전자책 빌드 — 「나는 AI에게 종목을 묻지 않았다」

MS Word 원고(`.docx`)를 **시인성 좋은 전자책**으로 자동 변환하는 파이프라인입니다.
긴 글 중 표·도식이 어울리는 부분을 자동/반자동으로 시각화하고,
출간용 **PDF**와 **EPUB**를 생성합니다.

## 산출물
| 파일 | 설명 |
|------|------|
| `build/book.pdf`  | 고정 레이아웃 PDF 전자책 (B6 판형, 자동 목차·페이지번호) |
| `build/book.epub` | 리플로우 EPUB (리디북스·교보·Apple Books 등 호환) |
| `build/book.html` | 미리보기용 디자인 HTML |
| `build/cover.png` | EPUB 표지 이미지 |

## 디자인 톤
깔끔한 실용서 + 부드러운 교양서. 따뜻한 아이보리 지면, 네이비 주조색, 골드 포인트.
폰트: 본문 Noto Serif CJK KR / 제목·UI Noto Sans CJK KR.

## 자동 처리 내역
- **제거**: 집필 메타(운영규칙·버전관리표·보류목록), 본문 속 `집필 메모`, 메모 박스
- **변환**:
  - 닫는 문장형으로 잘못 매겨진 제목 18개 → 우아한 *마무리 인용구*
  - 좋은 기업 vs 좋은 주식 → **비교표** (5장)
  - 장전 5모드 → **선택 바** (8장)
  - 장마감 루틴 → **5단계 흐름도** (9장)
  - 급등 5유형 → **분류 카드** (13장)
  - AI에게 이렇게/저렇게 묻기 → **Do/Don't 박스** (16·17장)
  - 부록 A 20질문 → 카테고리 배지 + 질문 + *붙여넣을 프롬프트* 박스
  - 부록 B~E → 단계·체크·문항 스타일
- **구성 보강**: 표지, 일러두기(판권), 자동 목차(페이지번호), 누락된 1·2부 표제지 삽입

## 빌드
```bash
# 의존성: pandoc, weasyprint, Pillow, Noto CJK/나눔 폰트
python3 ebook/build.py
```

## 다른 원고에 재사용
`ebook/source/raw.md`를 새 원고의 마크다운(예: `pandoc 원고.docx -t gfm -o raw.md`)으로
교체하면 동일 디자인으로 다시 빌드됩니다. 장/부/부록 패턴(`N장.`, `N부.`, `부록 X.`)을
따르면 자동 인식되며, 장별 표·도식은 `build.py`의 `comp_*` 함수에서 추가/수정합니다.
