# 14장. 처음 보고서에서 틀렸던 것들

## 핵심 아이디어
"AI는 틀린 숫자도 아주 그럴듯한 보고서로 만들어 줍니다." 틀린 보고서는 맞는 보고서와 똑같이 깔끔했다. 오류를 찾아낸 것도 AI였지만, 다시 묻는 것은 언제나 사람 몫이었다. "반대 의견을 내 달라고 요구하는 건 언제나 제 몫이었습니다."

## 소개하는 프레임워크
- **여섯 가지 정정과 배운 것**
  1. **"21년 연평균 9.1%"** → 2005~2013년 구간에 상장폐지 종목만 들어 있었다(현재 상장 종목 시세가 2014년 6월부터만 제공). 고친 뒤 2006~2026 +12.1%. 배운 것: 연도별 종목 수를 세어 본다.
  2. **"칸을 10개로 줄이면 −5.5%로 뒤집힌다"** → 실제는 10칸 +14.8%, 대신 최대 손실 −55.6%. 결론의 방향이 뒤집혔다. 배운 것: 요약 말고 표 전체를 본다.
  3. **"RSI는 고원이 아니라 절벽이다"** → RSI 14일 20·25 이하, 21일 25·30 이하 모두 위험 대비 수익 0.76~0.81. 무너진 건 RSI 7일이나 35 이상뿐. 전략을 버릴 뻔했다. 배운 것: 어느 방향으로 얼마나 바꿨을 때 무너지는지 묻는다.
  4. **"15일만 된다, 10일은 못하다"** → 격자로 다시 보니 짧을수록 좋고 10일 최적, 20일 이상 악화(칸이 막혀 다음 신호를 놓침). 단, 10일·−7%로의 변경도 시기별 성적을 본 뒤의 결정이다. 배운 것: 함께 움직이는 숫자(목표·기한)는 격자로 본다.
  5. **"수익 비율 64.3%"** → 신호 기준. 실제 체결 기준 60% 안팎. "신호 기준 숫자는 항상 실제보다 좋게 나옵니다." 배운 것: 승률이 신호 기준인지 체결 기준인지 묻는다. "유튜브의 승률은 거의 전부 신호 기준입니다."
  6. **"유일한 플러스 조합"(+4.0%)** → 시기 분할: 2005~2017 −1.5%, 2018~2022 −2.1%, 2023~2026 +58.3%. 파는 규칙 여덟 가지 중 의미 있는 플러스 두 개, 최대 손실 −69.4%. 조합 폐기, 외국인 3일 조건(거래당 +1.1~1.5%p)만 건짐. 배운 것: 기간을 나누기 전에는 아무것도 믿지 않는다.
- **계산 자체의 오류**: 2014년 −81%(날짜 순서 뒤섞임), 데이터를 받지 못한 종목이 "수익률 0%인 정상 매매"로 계산된 오류(빈칸을 0으로 채우는 기본 동작). 손실 전략은 덜 나빠 보이고 수익 전략은 덜 좋아 보인다.

## 핵심 개념
- **깔끔함의 위험**: "깔끔한 보고서는 의심을 잠재웁니다." 형식만 보고는 맞고 틀림을 구분할 수 없다.
- **역생존편향**: 생존편향을 피하려 사라진 회사를 넣다가 살아남은 회사를 빼먹었다.

## 사고 모델
- AI의 증명도 의심 대상이다. 증명을 요구한다는 건 AI가 내놓은 증명도 의심한다는 뜻이다.
- 틀린 숫자를 버린 기록이 신뢰의 근거다. "처음부터 맞았기 때문이 아니라 틀린 숫자들을 하나씩 버렸기 때문입니다."
- 최근 몇 년이 폭등장이었다면 전체 기간 숫자를 더 의심한다.

## 피해야 할 것
- **요약 결론만 받아들이기**.
- **한쪽 끝 붕괴를 전체 성질로 일반화**.
- **한 번에 숫자 하나씩만 바꿔 보기**.

## 실례
| 처음 보고 | 실제 | 바뀐 것 |
|---|---|---|
| 2005~2026 연평균 +9.1% | 2006~2026 연평균 +12.1% | 데이터 구멍 |
| 10칸이면 −5.5%로 손실 | 10칸이면 +14.8%, 대신 최대 손실 −55.6% | 결론의 방향 |
| RSI는 절벽 | RSI는 넓은 고원 | 전략을 버릴 뻔함 |
| 15일만 작동 | 10일이 최적 | 규칙의 숫자 |
| 수익 비율 64.3% | 실제 체결 60% 안팎 | 기대치 |
| 3개 조건 +4.0% | 앞 두 시기 모두 손실 | 조합 폐기 |

AI가 준 결과를 받았을 때 던지는 여섯 질문: 1) 연도별로 쪼개면? 기간마다 데이터가 온전한가? 2) 요약 말고 표 전체를 보면? 3) 숫자를 어느 방향으로 얼마나 바꿨을 때 무너지는가? 4) 같이 움직이는 숫자들을 격자로 놓고 보면? 5) 신호 기준인가, 실제 체결 기준인가? 6) 기간을 셋으로 나누면 셋 다 플러스인가?

## 핵심 정리
1. 연도별 종목 수·데이터 완전성부터 확인한다.
2. 결론 문장 대신 표 전체를 요구한다.
3. 승률은 체결 기준으로 다시 받는다.
4. 결측을 0으로 채우지 않았는지 확인한다.
5. 기간 분할은 마지막이 아니라 필수 단계다.
