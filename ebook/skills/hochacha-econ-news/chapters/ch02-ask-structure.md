# 2장. AI에게 답을 묻지 말고 판단 구조를 시켜야 합니다

> 학습용 요약입니다. 특정 금융상품의 매수·매도 권유가 아닙니다.

**핵심 질문**: AI에게 무엇을 물어야 경제뉴스가 공부로 바뀌는가?

## 핵심 아이디어
"이 뉴스 앞으로 어떻게 될까요?", "이 종목 오를까요?", "이 ETF 사도 될까요?", "지금 뭐 사야 하나요?"는 판단 과정을 건너뛴다. "AI에게 답을 요구하면 의존하게 됩니다. AI에게 구조를 요구하면 공부가 됩니다." 이 문장이 책 전체의 사용법이다.

## 프레임워크
- **좋은 AI 질문의 공식 (5요소)**

| 요소 | 질문에 넣을 내용 | 예시 |
|---|---|---|
| 역할 | AI가 어떤 관점으로 답해야 하는가 | 초보 직장인에게 경제뉴스를 설명하는 금융교육 강사 |
| 목적 | 왜 이 답변이 필요한가 | 경제뉴스를 내 돈의 언어로 이해하기 위해 |
| 분류 기준 | 어떤 순서로 나눌 것인가 | 금리, 환율, 섹터, 기업실적, 내 계좌 |
| 제한 조건 | 무엇을 하지 말아야 하는가 | 특정 금융상품 매수·매도 권유 제외 |
| 검증 요청 | 무엇을 다시 점검할 것인가 | 반대 시나리오와 확인할 사실 구분 |

- **반드시 요구할 3가지**: 근거(단순 결론 탈피), 반대 시나리오(쏠림 방지), 확인할 사실(그럴듯한 문장 맹신 방지).
- **AI 답변 3분류 읽기**: 일반적인 경제 원리("금리 상승은 성장주에 부담이 될 수 있다") / 현재 시장 상황 해석("지금 시장은 물가보다 고용지표에 더 민감하다") / 확인이 필요한 사실(최신 CPI 수치, 기준금리, 기업 실적, ETF 구성종목).
- **프롬프트 3종**: 1. 뉴스 분해(연결고리 찾기) → 2. 답변 검증(빈틈 찾기) → 3. 한 줄 기록(내 언어로 남기기). 원문은 prompts.md.
- **하루 10분 루틴**: 1분 시장 분위기 / 2분 금리 / 2분 환율 / 3분 핵심 뉴스 1개 / 2분 내 돈과 연결(대출, 연금, ETF, 현금 비중). 목적은 매매가 아니다.

## 핵심 개념
- **판단 구조**: 결론 대신 생각하는 순서. 근거·조건·반례가 보이는 답.
- **막연한 질문**: "미국 물가 뉴스 설명해줘"는 나쁘진 않지만 너무 넓어 답이 흩어진다.

## 사고 모델
- 막연한 질문은 막연한 답을 만든다. 질문이 구체적이면 공부도 구체적이다.
- "AI를 믿는 법" 대신 "AI를 의심하면서 잘 부리는 법"을 익힌다.
- 긴 프롬프트를 외울 필요 없이 역할·목적·기준·제한·검증 원리만 기억한다.

## 피해야 할 것
- **답 받아 적기**: 근거와 틀리는 조건, 내 상황 적합성을 알 수 없어 기준이 생기지 않는다.
- **프롬프트 수집**: 많이 모으기보다 자주 쓰는 세 가지를 익힌다.

## 실례
선배가 기사 링크와 "이거 봤어? 앞으로 어떻게 되려나." → 예측형으로 물으면 보낼 말이 없다 → 기사를 핵심 사건·금리·환율·섹터·기업실적·내 계좌 순서로 분해 요청, 반대 시나리오 추가 질문, 한 줄 기록 → 답장: "저는 환율 쪽이 먼저 걸리네요. 오늘 수치부터 확인해 보려고요." (원리와 확인할 사실이 가려진 답장)

## 핵심 정리
1. AI에게 답을 묻지 말고, 경제뉴스가 내 돈까지 오는 경로를 묻는다.
2. 질문 안에 역할·목적·분류 기준·제한 조건·검증 요청 5요소를 넣는다.
3. 근거·반대 시나리오·확인할 사실 3가지를 매번 요구한다.
4. 답변은 원리/현재 해석/확인할 사실로 나눠 읽는다.
5. 아침에 방향, 퇴근 후 복기, 주 1회 흐름 확인.

## 연결
- **1장**: 분류 기준(6단계)의 출처.
- **19장**: 답변 검증을 팩트체크 절차로 확장.
- **20~22장**: 하루 10분 루틴과 주간 루틴, AI 선생 만들기.
- **부록 1**: 3대 마스터 프롬프트.
