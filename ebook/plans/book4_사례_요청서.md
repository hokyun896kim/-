# 『호재일까, 함정일까』(구 가제 『호재일까, 함정일까』) 사례 요청서

장마다 **실제 공시 1건**이면 충분합니다. 칸을 다 채우지 않아도 됩니다 — **종목명 + 공시 날짜**만 주시면 나머지(원문 표, 그 뒤 주가·실적)는 제가 확인해 채웁니다.
책에는 회사 이름을 가리고(A사·B사) 접수일만 적습니다.

## 좋은 사례의 조건
- 뉴스 제목과 공시 원문을 같이 보면 **읽는 느낌이 달라지는** 공시
- 결과가 **좋게 끝난 것과 나쁘게 끝난 것이 섞이게** (좋은 사례만 모으면 2권 원칙 위반)
- 가능하면 **공시 후 6개월 이상 지난 것** (그 뒤에 무슨 일이 있었는지 확인하려고)
- 공시한입에서 다룬 공시면 가장 좋습니다

## 장별로 필요한 사례

| 장 | 필요한 공시 | 이런 게 좋아요 | 종목명 | 공시일 | 왜 골랐나(한 줄) |
|---|---|---|---|---|---|
| 프롤로그·1장 | 단일판매·공급계약 + 같은 날 기사 | 기사 제목은 "대규모"인데 원문을 보면 계약 기간이 길거나 조건이 붙은 것 | | | |
| 3장 | 유상증자 결정 | AI에게 요약시키면 놓치기 쉬운 조건(배정 방식·할인율·자금 용도)이 있는 것 | | | |
| 4장 | 단일판매·공급계약 | 계약 뒤 **정정 공시로 금액이 줄었거나 해지된** 것이면 최고 | | | |
| 5장 | 영업(잠정)실적 | 매출·이익은 늘었는데 **시장 기대보다 낮아** 주가가 빠진 것, 또는 그 반대 | | | |
| 6장 | 자기주식 취득(신탁) 결정 | 발표 규모만큼 **실제로 다 사지 않은** 것, 또는 소각까지 이어진 것 | | | |
| 7장 | 유상증자 결정 | 주주배정 또는 제3자배정, **채무상환 목적이 큰** 것 | | | |
| 8장 | 전환사채(CB) 발행 결정 | **리픽싱으로 전환가액이 내려간** 것, 여러 회차를 연달아 발행한 회사 | | | |
| 9장 | 최대주주 변경(주식양수도계약) | 경영권 프리미엄이 붙은 것, 변경 뒤 CB·유상증자가 이어진 것 | | | |
| 10장 | 감사의견 비적정 / 조회공시 "미확정" 답변 / 반복 정정 | 셋 중 하나만 있어도 됨 | | | |
| 11장 | 공급계약 등을 발표했는데 **후속 공시가 없던** 것 | 계약 기간이 끝났는데 이행 결과가 안 나온 것 | | | |
| 12장 | 관리종목 지정 또는 거래정지 → 상장폐지 | 지정 몇 년 전부터 경고 공시가 쌓였던 회사 | | | |

## 작가님 경험 (있으면 1인칭으로 다시 씁니다)

| 자리 | 필요한 것 | 내용 |
|---|---|---|
| 프롤로그 | 뉴스보다 공시를 먼저 봤던 순간, 또는 제목과 원문이 다르게 읽혔던 경험 | |
| 13장 | 실제로 쓰는 공시 확인 루틴 — 앱·알림 설정·시간대·기록 방식 | |
| 14장 | 공시를 보고 판단했다가 맞았던/틀렸던 경험 하나 | |
| 저자 소개 | "매일 장이 끝나면 공시를 먼저 연다"가 실제 습관과 맞는지 | |

## 같이 있으면 좋은 것
- **OpenDART 인증키** — 사례 숫자를 공식 API로 정확하게 모으고, 14장 검증표(같은 유형 공시 여러 건의 평균 반응)를 채울 수 있습니다. 발급: opendart.fss.or.kr 회원가입 → 인증키 신청(무료). 키는 채팅에 붙여 넣지 말고, 제가 띄우는 보안 입력창에 넣어 주세요.
- **②권 시세 데이터를 다시 써도 되는지** — 14장 검증에 사용
