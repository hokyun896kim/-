# 용어집 (가나다순)

**가운데값** — 성적순으로 줄 세웠을 때 한가운데 사례. 평균과 차이가 크면 소수 대박이 평균을 끌어올린 것(볼린저 돌파 평균 −1.17%p, 가운데값 −6.33%p) (4장)
**계좌 실험** — 계좌를 여러 칸으로 나눠 신호가 나면 빈 칸에 사고 규칙대로 파는, 실제 매매에 가까운 검증 (5·9장)
**고원** — 숫자를 넓은 범위에서 바꿔도 성적이 비슷하게 좋은 상태. 시장의 성질을 잡고 있을 가능성이 크다 (9·13장)
**급락 반등** — 당일 −7% 이상, RSI(21) ≤ 25, 투자심리선(10) ≤ 25, 스토캐스틱 %K(7,3,5) ≤ 20 종목을 사서 +20% 또는 10일에 파는 규칙 (11장)
**기준선(무작위 + 12% 익절)** — 아무 종목이나 사서 +12% 또는 60거래일에 파는 비교 기준. 21년 연평균 +4.7% (2·9장)
**다중 검정** — 많이 시도하면 우연만으로도 좋은 결과가 나오는 현상. 12,873회 시도 시 우연 최고 1.63 (13장)
**매집형** — 외국인은 사는데 주가는 빠지는 종목. 21년 데이터에서는 좋았고 표본에서는 평균 수준 (7장)
**미래 엿보기** — 장이 끝나야 아는 정보로 장중에 산 것처럼 계산하는 오류. "오늘 종가로 판단, 다음 날 시가 매수"로 막는다 (2장)
**봉우리** — 숫자 하나에서만 성적이 좋은 상태. 우연히 맞은 숫자일 가능성이 크다 (13장)
**블록 부트스트랩** — 기간을 덩어리째 무작위로 다시 뽑아 반복 검증. 과매도 반등 위험 대비 수익 0.75 [0.43, 1.14] (13장)
**사후 선택** — 성적을 본 뒤에 숫자나 조합을 고르는 것. 3부 숫자 대부분이 해당 (11·13·14장)
**생존 편향** — 살아남은 회사만으로 계산해 결과가 좋아 보이는 함정. 상장폐지 983개 포함으로 피함 (2장)
**손바뀜** — 거래량 폭발일은 누가 산 날이 아니라 주인이 바뀐 날. 파는 쪽은 대개 먼저 와 있던 사람 (3장)
**신호 기준 vs 체결 기준** — 모든 신호를 샀다고 가정한 성적과 칸 제약으로 실제 체결된 성적. 신호 기준이 항상 더 좋다 (14장)
**위험 대비 수익** — 샤프 비율. 수익을 변동성으로 나눈 값 (1장 외)
**이탈형** — 외국인은 파는데 주가는 오르는 종목. 전 시기 마이너스, 표본 −2.14%p (7장)
**정배열** — 짧은 이동평균이 긴 이동평균 위에 차례로 쌓인 상태. 판별력은 있으나 너무 흔하다(하루 평균 17%) (5장)
**정배열 눌림목** — 정배열 종목이 20일선 ±3%까지 쉬었다가 양봉, RSI(21) ≥ 70일 때 사는 규칙 (10장)
**조건 제거 실험** — 조건을 하나씩 빼며 짐과 필터를 가르는 해부 (8장)
**지수 과매도 반등** — 코스피 RSI(21) ≤ 30이면 코스피 200 ETF를 사서 +5% 또는 20일에 파는 규칙 (12장)
**초과수익(같은 날·같은 덩치 대비)** — 같은 날, 같은 거래대금 구간(5등분) 평균 대비 수익 (1·2장)
**칸** — 계좌를 나눈 단위. 한 칸에 한 종목. 칸 수가 낙폭과 체결률을 바꾼다 (6·9·11장)
**타이밍 이득** — 신호 종목을 그냥 보유한 것 대비 규칙 매매가 더한 수익. 눌림목은 0.2~0.7%p (10장)
**투자심리선** — 최근 N일 중 오른 날의 비율. 10일 기준 25 이하 = 오른 날 2일 이하 (11장)
**판별력** — 같은 날 다른 종목보다 나은 쪽을 고르는 능력. 돈(실제 플러스)과 다르다 (5장)
**해마다 갈아타기** — 매년 과거 최고 조합으로 바꾸는 방식. 2011~2026 일봉 +0.6% vs 코스피 +7.9% (13장)
**2층 구조** — 코스피 120일선 위에선 보유, 아래에선 과매도 반등만. 연 +11.6%, 최대 손실 −42.2%, 수익 비율 37% (12장)
