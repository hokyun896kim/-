# 제출 규격과 거절 대응

## 유페이퍼 (전자책) — 출처: 유페이퍼 『승인 검수 기준』(2026-01)과 실제 거절 회신 2건
**표지**
- 700×1000 ~ 1400×2200px, 72dpi 권장 → 우리 `표지_1240x1835.jpg` (고해상도본은 올리지 않는다)
- 제목·저자명·출판사명 필수. 개인 저자는 출판사명 "유페이퍼". 등록 정보와 글자까지 같게
- 부제가 제목보다 크면 거절, 글자가 너무 작으면 거절, 가장자리 흰 여백 거절(쓰려면 테두리선), 펼침 표지 거절

**판권(마지막 쪽)** — 필수 5항목, 거절 회신의 표기를 그대로 쓴다
| 항목 | 표기 예 |
|---|---|
| 도서명 | 그 매매법, 정말 통했을까 |
| 저자명 | 호차차 (AI로 작성한 내용이면 AI 명칭 + 본인 이름 — 저자 결정 사항) |
| 출판사명 | 유페이퍼 |
| 발행일 | **2026년 11월 20일** (연·월·일 모두, 신청일로부터 15일 이상 뒤) |
| 가격 | **8,900원** (판매 신청 가격과 동일, 도서정가제로 변경 어려움) |
ISBN은 판권에 넣지 않는다(승인 후 발급분은 판권 교체가 어려움).

**EPUB** — 2.0만 가능(3.0 등록거부) · 목차 2개 이상 100개 이하 · 빈 목차 금지 · 목차 html 1개 200KB 이하 · 문단 중간 줄바꿈 금지 · 30MB 이하 · 폰트 임베드 최소화

**PDF** — 모든 쪽 같은 크기 · 텍스트 선택 가능 · 빈 쪽 2개 이상 금지 · 첫 쪽 = 업로드 표지와 같은 그림 · 마지막 쪽 판권 · 책갈피 · 보안 해제 · 70MB 이하

**가격 관례** — 300쪽 종이책 ≈ 전자책 1만 원. 품질 대비 비싸면 거절 사유. 2만 원 초과는 별도 요청.

**재신청** — 신규 등록하면 무조건 거절. 판매대기 전자책 → "수정" → 파일 교체 → "전자책수정" + "기본정보저장" → 목록에서 "판매". 버튼을 빠뜨리면 예전 파일이 남는다.
